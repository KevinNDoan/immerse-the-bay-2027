## Update 2026-11-15: new typeface, Bricolage Grotesque

- The Figma file now uses Bricolage Grotesque for all text. This covers the seven text styles, the component labels and the controls card labels. The ZAP! wordmark and app icon keep their own lettering.
- Added to `Assets/_Project/Art/Fonts/`:
  - `BricolageGrotesque-Regular.ttf`, `-Medium`, `-SemiBold`, `-Bold`, `-ExtraBold` (stored in Git LFS)
  - the licence, `BricolageGrotesque-OFL.txt` (SIL Open Font License 1.1)
- **Source:** the static TTFs come from the upstream project, https://github.com/ateliertriay/bricolage (`fonts/ttf/`), which Google Fonts' `METADATA.pb` lists as the source. The licence comes from `google/fonts/ofl/bricolagegrotesque/OFL.txt`. Google Fonts itself only ships a variable font, which TextMeshPro does not handle well.
- Checked: each file starts with a valid TrueType header and matches the size GitHub reports.
- **Automatic setup, written but not compiled or run.** `ZapThemeAssetBuilder.BuildFontAssets` (menu **ZAP > Build Font Assets**):
  - It makes dynamic TextMeshPro font assets (SDF, 90 pt sampling, 1024 atlas, multi-atlas): `BricolageGrotesque-Regular SDF.asset` and `BricolageGrotesque-SemiBold SDF.asset`, in `Art/Fonts/`.
  - It fills them with basic Latin and punctuation, and sets `ZapTheme.font` to the Regular one.
  - `ZapArtImporter` runs it automatically when Unity imports a `.ttf` in `Art/Fonts/`.
  - The Unity Editor was closed, so none of this has run yet. The TextMeshPro calls were checked against the installed `com.unity.ugui` source.
- **To finish, in Unity 6000.6.9f1:**
  1. Open the project. The Console should log "ZAP: font asset created …" twice and "ZAP: theme font set to Bricolage Grotesque Regular". If it doesn't, run **ZAP > Build Font Assets**.
  2. Press Play in `Void` and check the note and controls text. Then build, and check on the headset that the text isn't blurry or missing letters.
  3. Commit the `.ttf.meta` files, both `SDF.asset` files with their `.meta` files, and `ZapTheme.asset`.
- **Known issue:** dynamic font assets keep adding characters to their atlas while you work in the Editor, so the `SDF.asset` files may show as changed in Git after Play mode. Commit them once, then undo later changes unless new characters are needed.
