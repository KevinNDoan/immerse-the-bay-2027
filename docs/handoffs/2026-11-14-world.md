## Finished and checked

- `Assets/_Project/Scripts/Net/`:
  - `Zap.Net.asmdef`: Assembly definition for networking.
  - `RelayConfig.cs`: Static `BaseUrl` (default `http://127.0.0.1:8787`, overridable by `zap_relay_url` TextAsset in Resources) and WebSocket URL derivation (`ws://` / `wss://` for `/ws/world`).
  - `RelayMessages.cs`: Fully typed, `JsonUtility`-serializable message classes for client and server JSON messages (`enter`, `steer`, `exit`, `ping`, `status`, `prompt`, `pong`, `error`, and HTTP `health`).
  - `RelayClient.cs`: Managed `ClientWebSocket` handling background I/O, outgoing send queue, binary 13-byte header parsing (seq, ts_us), dropping stale JPEG frames, dispatching status/prompt/error events to main thread, and auto-reconnecting with 1s/2s/4s/8s exponential backoff.
- `Assets/_Project/Scripts/World/`:
  - `Zap.World.asmdef`: Assembly definition referencing `Zap.Net` and `Unity.InputSystem`.
  - `Resources/ZapDome.shader`: Unlit URP shader named `Zap/Dome` with `Cull Front`, single-pass instanced stereo support, and black out-of-bounds clamping for `Front` mode.
  - `DomeView.cs`: Procedural inside-out sphere mesh (radius 5m, 64x32 segments) tracking camera position without rotation, hidden until entered, supporting runtime switching between `Wrap` (equirectangular panorama) and `Front` (110°x62° patch).
  - `WorldStream.cs`: Reused `Texture2D` decoding latest JPEG frame via `LoadImage` at most once per `Update`.
  - `WorldSession.cs`: Public coordinator exposing `Enter`, `Exit`, `Steer`, `State`, and events.
  - `WorldInstaller.cs`: Runtime initializer creating `[ZAP World]` root object on `AfterSceneLoad`.
  - `WorldDebugKeys.cs`: Input System debug keys (`E` enter, `Q` exit, `M` mode toggle, arrows for steer) logging status and prompt events.
- `Assets/_Project/Tests/World/`:
  - `Zap.World.Tests.asmdef`: PlayMode test assembly definition with `UNITY_INCLUDE_TESTS`.
  - `WorldStreamPlayModeTest.cs`: NUnit `[UnityTest]` verifying health check timeout fallback, stream arrival (>= 5 frames, 832x480 resolution, state transition to streaming), steer prompt roundtrip (< 5s), and clean exit.
- Code reviewed line-by-line for correct types, assemblies, namespaces, and missing usings.
